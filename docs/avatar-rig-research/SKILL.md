# 아바타 리그 연구

이 디렉터리는 스킬로 전환할 수 있도록 작성한 문서 초안이다. 현재 자동 탐색 경로에 설치하지 않았다. 적용할 때는 사용자 과제의 범위를 우선한다.

## 목적과 자료 선택

사용자 입력으로 반복·재현 가능한 2D/2.5D 캐릭터 변형을 연구한다. 틈을 없애는 것과 자연스러운 형태를 만드는 것을 별도 성과로 다룬다.

- 이 실험을 이어갈 때: [실험 노트](references/experiments.md)와 [세션 인계](references/handoff.md)를 읽는다.
- 다른 아바타에 적용할 때: 실험 노트의 실패 유형·평가 방법을 참고하되, 이 캐릭터의 좌표·각도·제어 수·의상 규칙을 복제하지 않는다.
- 다음 세션 시작용: [프롬프트](NEXT_SESSION_PROMPT.md).

## 연구 절차

1. 대상 관절, 시점, 움직임 축, 의상, 원화, 입력 방식을 명시한다. 가능하면 한 큰 관절과 한 동작으로 좁힌다.
2. 변경 전 결과를 보존한다. 소스 버전, 원화 해시, 각도/자세, 화면 배율, 표시 모드를 기록한다. 기존 사용자의 변경을 덮어쓰지 않는다.
3. 결함을 분류한다: 접합 틈, 윤곽 붕괴, 두께/부피 손실, 불필요한 변형 전파, 가림 오류, 원화 부족, 음영 오류, 입력 흔들림.
4. 한 번에 한 가설을 검증한다. 뼈 수, 메쉬 밀도, 가중치, 보정 형태, 의상 구속, 물리를 동시에 바꾸지 않는다.
5. 정지 자세의 단색 실루엣을 먼저 검토한다. 뼈/메쉬 오버레이와 확대·전체 보기를 병행한다. 음영이나 카메라 변화로 결함을 가리지 않는다.
6. 기준 자세가 타당하면 중간 각도와 왕복을 검사한다. 같은 입력에 대한 재현성, 각도 경계의 튐, 성능도 확인한다.
7. 피부가 통과한 뒤 의상을 추가한다. 몸과 같은 골격을 참조할 수 있지만 의상은 별도 표면·가중치·부착/접촉 관계를 가진다.
8. 물리는 흔들림·탄성·접촉 등 가설상 필요한 현상에 추가한다. 정지 자세의 오류를 물리로 해결했다고 간주하지 않는다.
9. 관찰과 가설을 구분해 기록하고, 시각 평가가 실패하면 수치 검사가 통과했어도 실패로 남긴다.

## 구현 판단 기준

- 관절을 늘릴 때는 각 제어점의 역할과 영향을 받는 영역을 설명한다. 해부학적 명칭만 붙이거나 거리순 가중치를 추가하는 것은 검증이 아니다.
- 메쉬 정점은 윤곽·접힘·재질 경계의 표현력이 부족할 때 추가한다. 잘못된 가중치를 고밀도 메쉬로 해결하려 하지 않는다.
- 피부 접합은 공유 정점 또는 대응 경계 제약으로 정의한다. 연결된 전체 영역이 같은 방식으로 늘어날 필요는 없다.
- 큰 회전의 모양은 보조 제어와 자세별 보정 형태를 후보로 둔다. 알고리즘 결과를 촘촘히 샘플링한 캐시는 올바르게 제작된 보정 형태가 아니다.
- 의상 전체 고정과 피부 가중치 전체 복사는 모두 가설로 평가한다. 의상 부위별 부착·미끄러짐·접촉·늘어남 제한을 구분한다.
- 원화 한 장에 없는 면은 색 채우기만으로 복원되지 않는다. 필요한 숨은 면, 깊이, 가림, 선화 정보를 별도로 식별한다.
- 화면을 2D로 유지하면서 내부에 단순 3D 형태를 쓰는 선택도 가능하다. 깊이·충돌을 검증할 필요가 있을 때 비교한다.
- ARAP, BBW, XPBD, 상용 리깅 도구는 후보 수단이다. 특정 엔진을 도입하는 것 자체를 성공 기준으로 삼지 않는다.

## 평가와 결과 보고

다음 세 판정을 분리한다.

1. 기하/입력: 연결, 길이, 뒤집힘, 변형 범위, 입력 연속성.
2. 시각: 윤곽, 두께, 겨드랑이 접힘, 의상 형태, 선화·음영·가림.
3. 조작: 임의 각도 접근, 왕복, 빠른 입력, 지연과 프레임 안정성.

통과 기준은 실험 전에 제안하고 근거를 기록한다. 수치 한계를 통과했다는 이유로 자연스러움을 선언하지 않는다. 특히 원본 정점 복원 테스트는 렌더링된 원화의 픽셀 보존 테스트가 아니다.

결과에는 가설, 비교군, 바꾼 변수, 관찰, 검사, 실패, 다음 판단을 남긴다. 실패한 후보를 완료된 리그로 본 화면에 확산하지 않는다. 이 실험의 사용자 목표는 큰 관절의 자연스러움이 먼저이며 미세 관절은 이후다.
