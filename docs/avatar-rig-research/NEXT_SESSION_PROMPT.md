목표는 영상 생성이 아니라, 사용자 입력에 따라 자연스럽게 움직이는 리그 연결 방법을 연구하는 것이다. 큰 관절을 먼저 완성하고 미세 관절로 진행한다.

현재 대상은 캐릭터의 왼쪽 어깨(화면 오른쪽), 수동 팔 벌림 한 축이다.
실험 화면: http://localhost:3000/live-avatar/2d/shoulder

현재 버전은 시각 평가 실패 상태다. 틈과 삼각형 뒤집힘 검사는 통과했지만 겨드랑이가 긴 피부 막처럼 늘어진다. 641개 각도 검사를 자연스러움의 증거로 취급하지 마.

현재 결과를 비교군으로 보존하고, 옷과 음영을 숨긴 상태에서 어깨·위팔·겨드랑이의 올바른 단색 실루엣부터 정의해줘. 먼저 관찰된 실패, 원인 가설, 이번에 바꿀 변수와 판정 기준을 짧게 설명한 뒤 하나의 통제된 실험을 진행해줘.

최소 리그 → 역할이 있는 보조 제어 → 자세별 보정 형태를 비교하되, 뼈 수·메쉬 밀도·물리를 동시에 바꾸지 마. 알고리즘 결과의 촘촘한 캐시를 검수된 기준 자세로 간주하지 마. 색 채우기나 옷 고정으로 피부 형태 문제를 덮지 마.

정지 기준 자세가 타당해진 뒤 중간 각도와 왕복을 검사해줘. 피부가 검증된 다음 의상 전용 부착/접촉을 다루고, 필요한 경우에만 물리나 내부의 단순 3D 형태를 별도 가설로 평가해줘.

저장소의 다른 미커밋 작업, 원화, 얼굴 리그, 기존 본 화면을 보존해줘. 결과는 수치 검사·시각 평가·조작 성능으로 나눠 기록하고, 실험 노트에 새 ID로 추가해줘.
